## 목적

같은 팀 개발자가 DataMonitor POC를 이어받을 때 막히지 않도록,
설치·실행·테스트에 필요한 정보를 한국어로 제공한다.

## 독자

같은 팀 개발자 (이어받기 목적)

## 언어

한국어

## 구조

| 섹션 | 내용 |
|------|------|
| 제목 + 한 줄 설명 | PoC 목적 명시 |
| 사전 조건 | Python 버전 |
| 시작하기 | 클론 → 서브모듈 초기화 → 가상환경 + 의존성 설치 |
| 실행 | `python main.py` |
| 테스트 | `pytest` 명령 |
| 프로젝트 구조 | 디렉터리별 역할 표 |
| 데이터 파일 | `data/` 위치 및 형식 한 줄 안내 |

## 제외 항목

- 아키텍처 상세 설명 (CLAUDE.md 참조로 대체)
- 확장·기여 방법
- 콘솔 메뉴 사용법 스크린샷
